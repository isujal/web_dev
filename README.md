# The Ducktators · FRC 11745 website

Static site: `index.html`, `css/style.css`, `js/main.js`, with GSAP + ScrollTrigger and Lenis vendored in `vendor/` (no build step).

Run locally:

```bash
python3 -m http.server 4321
```

Then open http://localhost:4321. Deploy the folder as-is to Vercel or GitHub Pages.

See `CONTENT_GUIDE.md` for what content is still needed and how to edit it.
